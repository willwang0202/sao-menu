# Desktop updates and local build implementation plan

> For agentic workers: use executing-plans for inline implementation of these tasks.

**Goal:** Build an installable local SAO Menu release with working manual update checks, automatic downloads, and explicit installation.

**Architecture:** An Electron main-process controller owns the updater and exposes bounded status/actions through the existing trusted IPC bridge. The renderer and tray share this status. GitHub stable releases provide merged architecture-aware feeds generated from the final verified installer reports.

**Tech stack:** Electron 44, electron-updater 6.8.9, React 19, TypeScript, electron-builder 26, GitHub Releases.

**Global constraints:** Preserve app identity/settings. No credentials or editable update server in the renderer. Do not quit the user's running app during tests. Downloads run automatically by default, installation requires the app's Install and restart control. Disable downgrades/prereleases. Full downloads avoid blockmap publication dependencies. Linux DEB uses manual installation. Current user authorization includes commits, main pushes and publishing releases. Use the existing renamed checkout.
