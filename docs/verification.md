# Current test release verification

The Apple Silicon 0.1.1 test release was built on October 3, 2026. Only the current `release/mac-arm64/SAO Utils 2.app` and `release/SAO Utils 2-0.1.1-arm64.zip` are retained. Git tracks its source, plans and checksum report on `main`; the release is tagged `v0.1.1`. This is the first Git snapshot, not reconstructed history of earlier builds.

- `npm test`: all 20 configuration, menu, surface/layout and account-service cases passed. Real SQLite account tests verify registration, login failure, mutual friend acceptance, rejected outsider messages, unread/read counts, durable history, friend removal and session revocation.
- Production TypeScript, Vite, Electron host/preloads and the universal Swift helper built successfully. The helper passed all 23 state checks.
- `node scripts/smoke-hover.mjs` passed against the final 0.1.1 build. Before the fix, native mouseleave and delayed DOM movement reset button artwork while the native cursor remained centered on Party; 3D child composition could also intercept hit testing. Desktop hover now shares the native cursor stream with click-through, and the launcher flattens its children while retaining perspective tilt. Root buttons and submenu rows keep one decoded hover face and their hover background through 12 repeated handoffs; leaving clears hover without a DOM event. Delayed hover artwork preserves the decoded normal face, and Reduced Motion keeps pointer tracking active.
- macOS vibrancy and the dialog backdrop blur were removed. The native hover check verifies transparent HTML/body/launcher styles, no backdrop filter and zero screenshot alpha outside the menu. Electron's `getBackgroundColor()` returns RGB only, so its value is not used as an alpha assertion.
- `node scripts/smoke-desktop.mjs` passed against 0.1.1: original fonts/sprite dimensions, fixed rail positions, selected-category anchoring, cascading menus, Calculator launch, native inside/outside click-through, bridge/IPC isolation, settings persistence, XML/JSON import/export and animated dismissal/hide/reopen. Fixtures supply cursor positions at the native input boundary and ignore unrelated physical clicks in other apps. Both native checks use disposable profiles.
- Native media acceptance passed for all 18 original gallery shaders, click pause/resume, wheel navigation, original frame settings, refresh/revocation, actual file drag/drop, source replacement and layout restoration. Closing previews removes their saved entries; quitting preserves them. The passive-wheel console warning was subsequently removed.
- The social UI is included, but its complete two-account native acceptance is pending. Its first test run exposed a test-harness problem: this installed Playwright version does not poll asynchronous `waitForFunction` predicates. Repair those waits before rerunning that social test.
- Packaging used the already installed Electron distribution and disabled certificate discovery. The resulting app is unsigned and not notarized. All 1,098 packaged renderer/host/icon files match the current build; the archive has no obsolete renderer files. The separate native helper and original ICNS also match. ZIP integrity passed, and the native Info.plist and archived package both report 0.1.1. [The package report](../output/current-package.json) records app archive and ZIP SHA-256 values; the verifier records only checks it performs.
- DMG creation failed because the sandbox could not create a disk image device. The stale previous DMG was removed; the ZIP contains the current app.

The earlier native browser/media baseline verified curved page click/typing/history, simultaneous image/GIF/video previews and outside/upward dismissal. Those surface checks were not repeated for this launcher-only correction. The user physically confirmed global downward invocation, outside dismissal and upward dismissal while another app was focused; this acceptance is retained.

Cloudflare hosting at `favioon.com` is authorized but not deployed. The packaged account form needs a compatible running service. No public accounts were created during testing; tests use disposable localhost identities. Complete original compositor behavior, preferences, remaining widgets and plug-ins are still parity work. See [compatibility](compatibility.md).
